# Local development accounts

Set `DEV_SEED_PASSWORD` before seeding. If omitted, the seed uses `ChangeMe!2026`; change it immediately outside local development.

| Role | Login |
| --- | --- |
| Administrator | `admin@local.invalid` |
| Teacher1 | `teacher1@local.invalid` |
| Each student | lowercase USN followed by `@local.invalid` |

These `.invalid` addresses are development-only account identifiers and are not personal contact information.
